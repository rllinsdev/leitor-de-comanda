Dúvidas frequentes

Como instalar o APK no Android?

Ao abrir o arquivo baixado, o Android pode pedir permissão para instalar apps de fontes desconhecidas. Toque em “Configurações”, ative a opção para o seu navegador e volte para concluir a instalação. Depois você pode desativar a permissão novamente.

O app é gratuito?

Sim, o download e o uso do app não têm custo para o cliente.

Preciso de internet?

Sim, uma conexão de dados ou Wi-Fi é necessária para consultar sua comanda atualizada.

A câmera não está lendo o código. E agora?

Verifique se há boa iluminação, limpe a lente e mantenha o código centralizado. Se persistir, peça ajuda a um atendente.

Quais celulares são compatíveis?

Celulares Android com processador de 64 bits (a maioria dos aparelhos atuais). A versão para iPhone ainda não está disponível.

Precisa de ajuda? Fale com um atendente do estabelecimento.
